# 📘 Atividade: Python Functions and Modules

## 🎯 Objetivo

Praticar a criação de funções reutilizáveis, organização de código em módulos e leitura e escrita de arquivos em Python para construir pequenos programas mais limpos e escaláveis.

## 📝 Tarefas

### 🛠️ Funções reutilizáveis

#### Descrição
Crie funções para executar operações simples, como calcular a média, validar entradas e formatar mensagens, reutilizando a lógica em diferentes partes do programa.

#### Requisitos
O programa concluído deve:

- definir pelo menos três funções com propósitos diferentes
- receber entradas do usuário ou parâmetros de função
- retornar valores ou imprimir resultados de forma clara
- evitar duplicação de código
- demonstrar que a mesma função pode ser chamada múltiplas vezes

### 🛠️ Organização em módulos

#### Descrição
Separe a lógica do programa em diferentes arquivos para melhorar a organização e a manutenção do código.

#### Requisitos
O programa concluído deve:

- criar pelo menos dois arquivos Python distintos
- manter funções principais em um arquivo e utilidades em outro
- importar corretamente módulos usando `import` ou `from ... import ...`
- garantir que o programa funcione mesmo quando a lógica está distribuída em arquivos diferentes

### 🛠️ Leitura e escrita de arquivos

#### Descrição
Implemente uma pequena aplicação para registrar dados em um arquivo e ler essas informações novamente.

#### Requisitos
O programa concluído deve:

- criar ou abrir um arquivo de texto ou CSV
- escrever dados coletados pelo usuário
- ler os dados armazenados e exibi-los em tela
- tratar erros básicos como arquivo inexistente ou entrada vazia
- manter a estrutura do programa organizada e legível

### 🛠️ Aplicação prática

#### Descrição
Use as funções e módulos criados para construir um pequeno programa útil, como um gerenciador de tarefas simples ou um registro de notas.

#### Requisitos
O programa concluído deve:

- resolver um problema prático do dia a dia
- reutilizar as funções criadas anteriormente
- permitir interação com o usuário
- armazenar informações em arquivo para persistência
- apresentar uma saída clara e amigável
